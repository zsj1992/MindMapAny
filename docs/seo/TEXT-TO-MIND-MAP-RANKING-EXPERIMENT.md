## 2. T0 基线

数据窗口：2026-07-16 至 2026-08-13，来源为 GSC 查询 × 页面 × 国家 × 设备导出。

- 精确词 `text to mind map`：3 次展现、0 点击、平均排名 95.7。
- 其中美国桌面端：2 次展现、平均排名 94.0；美国移动端：1 次展现、平均排名 99.0。
- 目标页全部已知查询：6 次展现、0 点击、平均排名 92.5。
- 精确词的 Google 选中页全部为 `/tools/text-to-mind-map`，当前没有页面归属冲突。
- `text2mind` 与 `text2mindmap` 属于观察词，不与精确主词混算结论。

样本极小，因此任何单日手工排名变化都只记为观察，不视为实验结果。

## 3. 归因规则

1. PDF 与 Text 本轮同批上线，但分别只改变各自页面的“任务完成与真实证据”变量组；不能把共同上涨简单归因给某一页。
2. 本轮继续冻结 Title、description、H1、通用正文、结构化数据和新增内链。
3. 每次操作必须记录实验编号、假设、Git commit、部署 ID、页面快照和对应 GSC 数据窗口。
4. 每 7 天导出一次数据；至少观察 28 天且精确词新增 30 次展现、Text 词簇新增 50 次展现，以最晚满足者为准。
5. 固定 `/tools/webpage-to-mind-map` 为共同站点级对照页；实验期间不改该页。
6. 按 query × page × country × device 判断，不能把不同国家或设备的排名直接平均成“当前名次”。

## 4. 操作路线

### 第 0 轮：基线监控（已完成）

假设：稳定的页面归属、索引和采集口径是后续归因的前提。

- 每周保存精确词、Text 词簇、目标页三组 GSC 筛选。
- 检查目标 URL 的收录、Google canonical、最近抓取时间、移动可用性。
- 保存线上 HTML、全页截图、Title、description、canonical、H1/H2 和 schema 哈希。
- 同步记录共同对照页的展现与排名，识别全站或算法波动。

可证伪条件：目标页不可索引、Google canonical 指向其他页，或精确词开始由其他页面承接。出现任一项时先修技术/归属问题，不启动体验实验。

### 第 1 轮：页面内完成真实任务（已完成本地实施，待部署）

假设：用户在排名页直接粘贴文本、生成并看到可编辑结果，会比仅有介绍与跳转的页面更符合工具型搜索意图。

只改变“页面内任务完成与可验证示例”这一组变量：

- 首屏直接提供文本输入与生成入口，保留真实限制和登录边界。
- 准备三个固定公开输入：产品发布笔记、会议纪要、学习笔记。
- 每个示例展示真实多层输出、编辑/折叠和导出能力，而不是静态示意图。
- 不在分析或实验档案中保存用户粘贴的文本、生成内容或其他敏感信息。
- 本轮冻结 Title、description、新内链和外链。

领先指标：`text_landing_input_started`、`mindmap_generation_started`、`mindmap_generation_completed`、生成成功率。  
排名指标：目标页精确词/词簇展现、平均与中位排名、页面归属。  
护栏：生成错误率、首屏性能、敏感文本不进入日志与分析。

### 第 2 轮：相关内链

仅在第 1 轮达到停止条件并作出保留/回滚决定后执行。

- 从首页工具区、`/tools`、相关笔记/文章页自然链接到目标页。
- 使用 `text to mind map tool`、`turn text into a mind map` 等自然变体。
- 不做全站精确匹配页脚链接，不新增近义薄页面。

### 第 3 轮：独立引用

页面稳定进入前 50 后，再发布可复现的 Text-to-Mind-Map 示例或评测资产，并争取少量真实相关引用。外链、内容和标题不在同一轮修改。

### 第 4 轮：CTR

仅当页面进入前 30 且单月相关展现达到 100 后，一次只测试 Title 或 description。

## 5. 决策标准

| 结果 | 判定 | 动作 |
|---|---|---|
| 页面归属稳定，词簇展现和排名改善，护栏正常 | 通过 | 保留并进入下一轮 |
| 排名无明确变化但样本未达停止条件 | 样本不足 | 继续观察，不追加变量 |
| 页面归属恶化、生成失败或性能显著变差 | 不通过 | 回滚该轮变量组 |
| 对照页同步同幅波动 | 外部因素可能性高 | 不归因给本轮操作，延长观察 |

SEO 不能证明绝对因果；这里用冻结变量、共同对照和固定观察窗口提高可复用性。

## 6. 上线后的查看时间

| 时间 | 看什么 | 能否下排名结论 |
|---|---|---|
| 上线当天（Day 0） | 部署 ID、线上 HTML/截图、canonical、H1、功能与分析事件 | 不能 |
| Day 3–7 | Google 是否重新抓取、页面是否仍被正确选中、输入→生成漏斗 | 不能，只排查故障 |
| Day 21 | 精确词和 Text 词簇的展现、页面归属、国家/设备排名趋势 | 只能做方向判断 |
| Day 28 或更晚 | 与 T0 和冻结对照页比较 | 达到新增 50 次词簇展现后才能保留/回滚 |

如果 Day 28 仍没有 50 次新增词簇展现，继续观察到 Day 42；不要因为时间到了就把噪声写成结论。
