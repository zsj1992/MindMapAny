## 防止关键词内耗

- `/tools/pdf-to-mind-map` 只服务 “打开工具并转换”；`how-to-convert-pdf-to-mind-map` 服务 “学习流程和核验方法”。
- 首页不争夺所有长尾词，只承接品牌与品类介绍。
- 比较页不复用工具页标题；必须注明测试日期、输入和限制。
- 同一查询同时出现工具与教程混合 SERP 时，保留两页并通过明确标题、内链和 schema 区分意图。
- 三个新工具页（docx / epub / pptx）必须各写独立说明与 FAQ，不能只换文件格式名复制 PDF 页——那是薄内容，会互相稀释。
