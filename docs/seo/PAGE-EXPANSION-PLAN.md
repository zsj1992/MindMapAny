# 内页与模块扩展规划

> 2026-08-12 · 依据 [`KEYWORD-LIBRARY.csv`](./KEYWORD-LIBRARY.csv)（102 词：42 live / 60 candidate）
> 上位判断见 [`SIMILARWEB-KEYWORD-REVIEW.md`](./SIMILARWEB-KEYWORD-REVIEW.md)、[`SITE-STRUCTURE.md`](./SITE-STRUCTURE.md)

## 先说结论：词库支持的新页面，比想象中少

60 个 candidate 按簇拆开后，真正能变成新 URL 的只有一小部分：

| 簇 | 词数 | 能不能建页 | 原因 |
|---|---:|---|---|
| generic | 25 | **不能** | `mind map`、`mind map maker`、`ai mind map generator` 是同一个宽泛品类的变体，归首页和支柱指南。为变体复制 URL 是自我内耗 |
| concept-map | 11 | **一页** | 见下方 C1。产品是树状层级，不支持任意节点连线，只能做「区别说明」不能声称支持 |
| youtube | 10 | ~~不能~~ **已建** | 2026-08-13 开放。端到端跑通后才建页，不是先占坑 |
| summarise | 5 | **不能** | 并入现有工具页和 `/blog/mind-map-vs-summary` |
| pdf / text | 7 | **不能** | 已有对应工具页，长尾合并进去做深 |
| markdown | 2 | **待定** | 见 M1，需先有 GSC 展现 |

**所以扩张方向不是「加页」，是「加模块」。** 现有 6 个工具页 + 4 篇博客还没吃透现有架构。

## 模块级机会（比新页面价值高）

| # | 模块 | 说明 | 前置 |
|---|---|---|---|
| B1 | **工具页首屏嵌入轻量输入框** | 现在工具页是「介绍 + CTA 跳工作台」。强交易意图词（`pdf to mind map`）的用户想直接用。多一跳就多一层流失 | 先看 CTA 点击率，别拍脑袋改 |
| B2 | **主题 → 图（不联网）** | Ask Anything 已经存在，只是强制联网检索 + 扣 3 积分。砍掉检索就是一个 `ai mind map generator` 的落地能力。约半天 | 无。generic 簇 25 个词全指向这个能力 |
| B3 | **`/m/[slug]` 质量门** | 公开脑图进 sitemap 前检查节点数、正文量、重复度。**当前不紧急**：图默认私有，必须用户主动公开 | 公开图达到两位数后 |

> B2 是唯一一个「generic 簇有 25 个词、我们一个都接不住」的直接解法，且成本最低。
> 但它解决的是**接得住**，不是**有人来**——先等 GSC 告诉我们有没有人来。

## 不做，以及为什么

- **模板库**：竞品 top100 里 `template / plantilla / テンプレート` 一个都没有。这是我们凭印象以为的需求，不是数据里的需求。
- **YouTube 相关任何页面**：产品端不支持。先建页 = 骗点击。
- **俄语/葡语/印尼语**：词库里有俄语词，但发孤立语言页不如把已有 7 种做深。
- **为 generic 变体建页**：`mind map` / `mindmap` / `mind mapper` 各建一页，是典型的关键词堆砌式内耗。
