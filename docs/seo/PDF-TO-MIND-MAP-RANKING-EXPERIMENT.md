# `pdf to mind map` 单关键词排名实验

建立日期：2026-08-16  
目标页面：`https://mindmapany.com/tools/pdf-to-mind-map`  
目标市场：Google 英文搜索，优先美国；同时保留国家与设备维度  
实验目标：找到可复现、可归因、可用于客户项目的排名提升动作，而不是用一次性大改制造无法解释的波动。

当前执行轮：[`PDF-EXP-001`](./experiments/PDF-EXP-001/README.md)。该目录中的 JSON 定义变量与停止条件，NDJSON 是只追加事件账本，`artifacts/` 保存带哈希的页面 HTML、截图与 SEO 元素快照。

| 查询意图 | 主查询 | 唯一主页面 |
|---|---|---|

## 3. 实验规则

1. 一轮只改变一组同类变量；标题、正文、内链和外链不能同一天一起改。
2. 每轮保存修改前页面 HTML、截图、Git commit、部署时间和 GSC 导出。
3. 每轮至少观察 21 天，或等目标词簇新增 50 次展现，以较晚者为准。
4. 每 7 天采集一次数据，但不到停止条件不提前下结论。
5. 保留 `/tools/webpage-to-mind-map` 作为站点级对照页，识别全站算法或品牌波动。`/tools/text-to-mind-map` 已进入独立监控实验，不能再作为未处理对照。
6. 不使用刷点击、批量低质目录、购买垃圾外链或大量近义词页面。

## 4. 分轮执行

### 第 0 轮：测量与索引控制

假设：只有主页面归属稳定、可索引且测量一致，后续实验才可归因。

- 部署已经完成的教程页意图拆分。
- 用 URL Inspection 检查工具页和教程页的收录、Google canonical、抓取时间和移动可用性。
- 校验 sitemap、canonical、hreflang、robots、状态码和渲染后 H1。
- 在 GSC 保存三个筛选：精确词、PDF 词簇、目标工具页。
- 建立每周快照脚本输出，并记录国家与设备。

成功标准：交易意图词逐步由工具页承接；不存在错误 canonical、noindex、软 404 或抓取异常。

### 第 1 轮：搜索意图与真实证据

假设：对工具型 SERP，打开即可操作并看到可验证结果，比继续增加泛说明文字更能提高页面质量与用户信号。

只修改目标工具页：

- 首屏提供真正的 PDF 上传入口，或至少可在原页面展开上传，而不是只跳转到另一个空白工作台。
- 保留精确 H1 `PDF to mind map`，标题前半段保持精确主词，后半段突出一个真实差异点。
- 添加一个固定、可合法公开的样本 PDF，展示输入特征、生成后的多层脑图截图和页码引用。
- 添加“如何核验输出”区块：点击节点页码、回到原 PDF、判断是否遗漏或错误归类。
- 明确支持范围：文本型 PDF、20MB、200 页；扫描件暂不支持 OCR，避免夸大承诺。
- 展示编辑、折叠、PNG/SVG/Markdown 导出结果，而不是只描述功能。
- 保留价格/免费额度、隐私和处理方式的明确说明。

主要指标：目标工具页的 PDF 词簇展现、平均/中位排名、交易意图词页面归属。  
护栏指标：落地页到开始上传率、生成成功率、首屏性能、跳出或快速返回信号。

### 第 2 轮：站内链接集中权重

假设：相关页面给出的上下文内链能帮助 Google 更稳定地识别 PDF 工具页是该词簇的主页面。

- 从首页相关工具区、`/tools`、PDF 教程、研究论文/电子书相关内容链接到目标页。
- 使用自然变体锚文本：`PDF to mind map tool`、`turn a PDF into a mind map`、`AI PDF mind map generator`。
- 教程正文在“开始转换”位置链接工具页；工具页继续反链教程，形成任务页 ↔ 方法页。
- 不在每个页脚重复堆精确匹配锚文本，不新增与现有页面同义的 URL。

主要指标：目标页内部入链数量与位置、Google 对交易词的页面选择、PDF 词簇排名变化。

### 第 3 轮：独立权威与可引用资产

假设：在页面和内链稳定后，少量高度相关的真实引用比批量目录提交更能推动从 30–50 名进入前 20。

- 发布可复现的 `PDF-to-Mind-Map Benchmark`：固定公开样本、评分规则、层级准确率、遗漏、页码可追溯性、测试日期和原始截图。
- 向研究工具、学习方法、知识管理、PDF 工作流相关作者或社区定向分发。
- 争取首轮 3–5 个真实相关域名的编辑型链接或产品提及。
- 外联以基准数据或可复现实例为价值，不交换垃圾链接，不购买站群链接。

主要指标：新增相关引用域、目标页/基准页入链、品牌查询、目标词簇排名。  
护栏指标：链接是否可抓取、上下文是否相关、锚文本是否自然、是否出现异常垃圾域。

### 第 4 轮：SERP 点击率实验

仅当页面稳定进入前 30 且单月获得至少 100 次相关展现后启动。

- 一次只测试标题或 description，不同时改正文。
- 候选标题围绕主词、可验证利益点和真实门槛，不写无法兑现的数字或“最佳”。
- 观察 CTR 时按相近排名区间、国家和设备比较，避免把排名变化误判为标题效果。

## 5. 阶段目标

| 阶段 | 成功信号 | 下一动作 |
|---|---|---|
| 90+ → 50 | 工具页开始稳定承接精确词，展现持续增加 | 继续真实证据与内链，不急着做 CTR |
| 50 → 30 | 多个 PDF 交易词进入前 50，页面归属稳定 | 启动少量相关外链与基准资产 |
| 30 → 20 | GSC 有足够展现，排名不再只靠长尾偶发 | 测标题/摘要和首屏转化 |
| 20 → 10 | 搜索意图、产品体验、引用域和品牌信号同时改善 | 扩展同簇用例，不复制薄页面 |

## 7. 立即执行顺序

1. 先部署并记录第 0 轮，确认工具页成为交易意图主页面。
2. 建立固定、可公开的 PDF 样本与脑图输出，这是当前最重要的内容资产。
3. 将上传入口或可展开的真实工具放到落地页首屏，完成第 1 轮。
4. 第 1 轮达到观察条件后再做内链；不要同一部署加入外链实验。
5. 页面进入前 50 后制作基准报告并开始定向获取相关引用。

## 8. 上线后的查看时间

| 时间 | 看什么 | 能否下排名结论 |
|---|---|---|
| 上线当天（Day 0） | 部署 ID、线上快照、PDF 上传/登录恢复/生成链路 | 不能 |
| Day 3–7 | Google 抓取、canonical、页面归属和生成成功率 | 不能，只排查故障 |
| Day 21 | PDF 词簇展现、排名方向和工具页是否开始承接精确词 | 新增至少 50 次词簇展现时可作初判 |
| Day 28 或更晚 | 与 T0、Text 实验和冻结对照页比较 | 满足停止条件后保留或回滚 |

本轮 PDF 与 Text 将按用户决定同批上线。如果两页与共同对照页同步波动，不把变化单独归因给某一个页面动作。
