# MindMapAny 产品增长实施路线图

> 2026-08-12 更新。日级任务、日期和验收标准见 [GROWTH-WORK-CALENDAR.md](./GROWTH-WORK-CALENDAR.md)。

## 当前已完成的基础

- [x] 六个真实可用输入及公开工具页：PDF、Text、Webpage、DOCX、EPUB、PPTX。
- [x] `/blog` 内容模型、工具目录、价格、支持、账单和法务页面。
- [x] `/app/*` noindex，公开内容与产品工作台分离。
- [x] WebSite、SoftwareApplication、BlogPosting、FAQ 和面包屑等结构化数据基础。
- [x] 英文默认站与六种本地化语言，canonical、hreflang 和多语言 sitemap 逻辑。
- [x] GA4 基础接入和生成开始/成功/失败事件。
- [x] Creem 产品、结账、Webhook、额度和订阅管理代码。
- [x] Chrome 插件开发和商店提交；公开入口在审核期间隐藏。

## Phase 1：收入与数据闭环（第 1–2 周）

- [ ] 完成 Creem 商户审核、KYC/KYB、收款账户和真实付款验证。
- [ ] 补齐落地页 CTA、注册、价格、结账和支付事件。
- [ ] 建立自然流量 → 成功生成 → 付费看板。
- [ ] 重做六个高意图工具页的首屏、真实案例、限制、FAQ、内链和 CTA。
- [ ] 验证 GSC 索引、sitemap 和主要查询基线。

完成标准：能够回答“哪个自然落地页带来了多少成功生成和收入”，并能完成一次真实付款闭环。

## Phase 2：产品成功与可信度（第 3–4 周）

- [ ] 降低各输入类型的解析与生成失败率。
- [ ] 完善上传前检查、生成进度、错误恢复和完成后的保存/分享/导出路径。
- [ ] 发布方法、限制和三个真实前后对照案例。
- [ ] 给公开分享页建立可索引质量闸门。
- [ ] 完善价格、信用点、取消、退款和支持说明。

完成标准：六种固定样本端到端通过；开始生成到成功生成率达到或接近 70%。

## Phase 3：交易型内容簇（第 5–8 周）

- [ ] Research Paper to Mind Map 落地页、教程和真实示例。
- [ ] PDF 页码引用与脑图质量方法内容。
- [ ] MindMapAny vs Mapify 和 Mapify alternatives 实测比较页。
- [ ] Students、Researchers、Knowledge Workers 三个独立用例页及 `/use-cases` 聚合页。
- [ ] 所有页面形成工具 → 案例 → 教程/比较 → 价格的内部链接。

完成标准：新增页面都有独立搜索意图、真实证据、主 CTA 和至少两个上下游内链。

## Phase 4：权威、国际化取舍与转化（第 9–12 周）

- [ ] 根据真实数据决定非英语市场的继续、暂停或补强。
- [ ] 完成全站 hreflang、canonical、sitemap 和索引复核。
- [ ] 发布可复现的 PDF-to-Mind-Map Benchmark。
- [ ] 获取至少 10 个相关域的有效外链。
- [ ] 运行一个有明确假设和护栏指标的转化实验。
- [ ] 完成 90 天页面分级、收入复盘和下一季度主战场选择。

完成标准：50–150 自然访问/天、核心页有效索引率 ≥ 90%、自然访问到付费转化率初期 ≥ 0.3%，或者已用数据明确指出最大阻塞点。

## 永久质量闸门

每次发布必须通过 lint、单元测试、生产构建、关键 URL 200、canonical、robots、sitemap 和移动端检查。重大架构、付款、索引与增长节点单独提交 Git。

以下情况禁止扩张：

- 付款闭环或额度发放不可靠。
- 生成成功率无法测量或低于可接受水平。
- 新页面没有独立意图、真实案例或可用功能。
- 现有页面仍有索引、canonical、hreflang 或重复内容问题。
- Chrome 插件尚未获批并完成生产端到端验证。
